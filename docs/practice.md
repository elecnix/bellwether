# Practice on the live fleet, 2026-11-28

On 2026-11-28, between 06:45 and 06:53 UTC, a parent practised each Bellwether feature on real machines, with Bellwether 0.1.10 (commit `3ea9698a4ed9`) and Claude Code 2.1.332. The parent was a Claude Code session on hawthorne, itself a child of a pi session on vandenberg. Each row below gives the command, the child, the pane and what the child record showed afterwards. Each defect the run found links to its issue.

## Scope of the practice

The practice ran from hawthorne, which reaches only one other machine, Vandenberg. Its herdr lists only Vandenberg, `sable` doesn't resolve as a host name there, and hawthorne doesn't have a key for it.

The parent couldn't hand the `sable` steps to a child on Vandenberg either. Its children were at depth 2 of 2, and `agent_request_depth` refused with `Your parent runs on another machine, and a depth request does not cross machines, so nothing was asked.` So the pi parent on vandenberg ran the three `sable` rows itself, and the table marks them. This run did not touch anticosti or the MacBook.

Practice from one machine can't cover a fleet of five. Read the table as one sweep from hawthorne plus three rows from vandenberg, not as a complete pass over every pair of machines.

## Results

Eleven of the twelve features exist on `main`, and all eleven did what they claim. The run turned up defects, each linked to its issue, and the eleventh row leaves a gap in what its record says. `bellwether free` isn't on `main` yet.
