`agent_adopt` now reads a pane id whose workspace id holds a letter, such as `w7R:p1`, as a pane on this machine. Before, it read `w7R` as the name of a machine. herdr gives a workspace an id like this once it has made more than a hundred. When this machine has no such pane and a saved herdr machine has the label `w7R`, the call refuses and names both readings, so the caller chooses one.
