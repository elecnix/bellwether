A daemon handed over from an SSH session starts without `SSH_AUTH_SOCK`, so a relay whose key lives only in an agent fails a retry later. `bellwether relay-bridge` now names each such relay when it hands the daemon over, and says what line to add to `~/.ssh/config`. `bellwether doctor` adds a line under each failing relay whose ssh ran without an agent. The daemon's lock records whether it started with one.
