A message pushed to a child's session that hasn't answered within 5 seconds stays in that session, and herdr no longer types a second copy, so a late answer can't put the same message in front of the child twice. Once that answer arrives, the record shows which adapter took the message. A start's brief in that state doesn't go again, and the spawn fails with `BriefNotTaken` when the model doesn't read it and begin a turn on it.
