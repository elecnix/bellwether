When herdr closes a child's old tab during a restart but returns an error, as a timeout does, the restart checks herdr's pane list. It starts the session in the new tab when herdr no longer lists the old pane, and closes the new tab when herdr still lists it; without a list from herdr, the reply says the old pane's state is unknown. While the close runs, the record keeps the old pane and marks it closing.
