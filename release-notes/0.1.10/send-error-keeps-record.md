An `agent_send` error now always matches the child record. When herdr's `agent.prompt` fails after herdr received the request, as on a timeout, herdr may have typed the message. The record keeps it, and the error gives its id and tells the caller to read the pane before sending again. Before, the call failed and wrote nothing to the record, while the child could still read the message, so a parent that retried had it typed twice. When the connection to herdr's socket fails, herdr never received the request, so the record marks the message as never delivered, and the error says that sending again is safe.
