Bellwether now delivers a message it never types, such as a teleport's notice, when its session next connects. Before this change, the reply and `bellwether doctor` said the session would receive it. It never did. The replay passed over each message still waiting for an adapter to take it, so the notice stayed on the record while the reply and the doctor line promised a delivery that was never going to happen. A push the session didn't answer within 5 seconds now shows in `agent_list` as in doubt, and a late answer makes it pushed. A read that arrives before the relay loses its answer leaves the message read. When a child on another machine retires after its session took a message, the parent no longer marks that message undelivered once the relay comes back. `agent_list` gives every message one of seven words: sending, held, pushed, in doubt, typed, read or undelivered. A self-restart that waits counts only the messages its model read or herdr typed, and a brief whose message the session reads after its start now shows as read.
