Each request that a session makes now ends by a deadline, and `bellwether doctor` prints every request still in flight with that deadline and the code that will end it, plus a `fail` line for a request past its deadline. A request is a restart that a session asked for of itself, a teleport that a child asked for, a move or teleport under way, or a retirement whose pane herdr no longer lists. Each module that touched a request used to decide on its own when the request was over. A restart could wait for hours with no deadline, and an act that refused could leave a request that nothing would end. When a stop cuts a teleport short, the daemon that recovers it now ends the child's own teleport request. The next daemon no longer arms a second teleport of a child already at its destination. Arming a waiting teleport again writes a fresh deadline. Bellwether refuses a second teleport request while one waits, and the refusal gives the machine and time of the first. A retirement intent now lists every worktree the child has on another machine, whichever path wrote it.
